# Инженер производственно-технического отдела — локальная копия

1. **Как открыть.** Откройте `index.html` двойным щелчком. Для просмотра сохраненных уроков и файлов сервер и интернет не нужны.

2. **Что сохранено.** Девять тем, 18 учебных блоков, 94 урока, 261 изображение со страниц уроков, 8 прямых вложений и 7 дополнительных файлов из папок проекта. После сверки 203 внутренних интерактивных страниц с оригиналом добавлены 67 иллюстраций и 86 PDF, доступных через кнопки скачивания на исходных страницах. Их изображения или ссылки на файлы показаны прямо в 140 раскрывающихся блоках уроков; оставшиеся 66 блоков содержат извлечённый текст. Файлы распределены по урокам, ссылки собраны под спойлером в конце соответствующих уроков и на странице `attachments/index.html`, доступной из боковой навигации. Реестр размещения — `file-placement.json`, результат сверки исходных страниц — `interactive-source-audit.json`, адреса и контрольные суммы новых материалов — `interactive-asset-map.json`, исходная карта курса — `source-map.json`. Сохранены вводные сведения 11 тестов. В 36 блоках на 25 страницах внешние материалы загружаются при доступном интернете; без соединения видна локальная ссылка «Источник и ограничения».

3. **Что не удалось сохранить или воспроизвести.** Не работают проверка ответов, анимация и иные серверные функции встроенных упражнений и тестов. PDF из интерактивных блоков получены с пустыми полями для названия организации и других пользовательских данных, поэтому персонализированные версии нужно создавать на исходном сайте. Внешние материалы не входят в автономную копию: их показ зависит от соединения, доступности площадки и разрешения на встраивание. Остальные внешние ссылки описаны в локальном списке источников. Некорректный адрес одной исходной внутренней ссылки удалён из рабочей карты; запись о нём сохранена в журнале очистки. Прямых видеофайлов и официальных ссылок на их локальное скачивание на просмотренных страницах не обнаружено. Визуальная проверка `file://` в автоматизированном браузере заблокирована его политикой URL.

4. **Происхождение и размещение.** 8 прямых вложений находились в материалах уроков. 7 перенесённых файлов размещены по тематическому соответствию; точный исходный URL каждого из них на платформе не подтверждён. 67 иллюстраций загружены из исходных встроенных страниц. 86 PDF созданы штатным экспортом этих страниц с незаполненными пользовательскими полями. Их адреса, размеры и SHA-256 записаны в `interactive-asset-map.json`. Повторяющиеся блоки материалов учебных разделов заменены подборками в конце конкретных уроков.

5. **Что нужно для устранения ограничений.** Для полноценной работы упражнений и тестов нужны официальные локальные пакеты с логикой и вопросами; для видео — разрешённые файлы или адреса скачивания. Для восстановления перехода по удалённой исходной ссылке нужен исправленный адрес. Для визуальной проверки откройте `index.html` в обычном браузере и сообщите о конкретной ошибке, если она появится.
6. **Проверка повторов файлов (24.09.2026).** Восемь дополнительных PDF с тем же учебным содержанием, что и экспорт из исходных упражнений, удалены из каталога и уроков; их копии отправлены в корзину Windows. Один похожий PDF с дополнительным определением сохранён. В каталоге устранены повторные ссылки на один и тот же файл, ссылки внутри соответствующих уроков оставлены. Результат сверки и SHA-256 — `audit/duplicate-files-2026-09-24.json`.

7. **Адресные исправления нормативных ссылок (24.09.2026).** В уроках уточнены подтверждённые обозначения ГОСТ, СП и санитарных документов, включая замену СП 246.1325800.2023 на СП 246.1325800.2026; в восьми уроках добавлено примечание об изменении пункта 5 приказа Минстроя № 344/пр приказом № 369/пр. У двух исходных PDF с устаревшим ГОСТ Р 21.101-2020 добавлены примечания. Сами PDF/DOCX сохранены без редактирования. Реестры проверок — `audit/gost-status-2026-09-24.json`, `audit/sp-status-2026-09-24.json`, `audit/ntd-edits-2026-09-24.json` и `audit/attachment-ntd-hits-2026-09-24.json`. Это адресная проверка выявленных расхождений, а не полная правовая экспертиза всех цитат курса; положения документов и требования к конкретному объекту следует сверять по официальной действующей редакции.

8. **Очистка хранилища (24.09.2026).** 22 подтверждённых временных, резервных и повторных файла (18,1 МБ) отправлены в корзину Windows, три пустые папки удалены. Восемь устаревших путей в `source-map.json` заменены путями к сохранённым экземплярам PDF; одна некорректная исходная ссылка исключена из рабочей карты. Устранены три повторяющихся якоря HTML. После очистки проверены 320 страниц, 13 916 ссылок и 1 119 путей в реестрах: пропавших локальных файлов, пустых ссылок и повторяющихся якорей нет. Карта удалённых файлов и результаты проверки — `audit/storage-cleanup-2026-09-24.json`; проверка читаемости PDF, изображений, архивов и аудио — `audit/storage-health-2026-09-24.json`. Системная корзина не очищалась: свободного места достаточно, удалённые файлы можно восстановить.
