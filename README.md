Этот репозиторий содержит главную страницу библиотеки и опубликованный курс Битрикс24. Курсы и вебинары Высшей инженерной школы размещены в отдельных репозиториях:

| 2 миникурса HES | [academy-hes-mini](https://github.com/zhidandbor/academy-hes-mini) | [Открыть миникурсы](https://zhidandbor.github.io/academy-hes-mini/) |

## Публикация

GitHub Pages публикует ветку `main`, папку `/docs`. Страница каталога находится в `docs/index.html`. Папка `docs/bitrix24/` обновляется действием **Publish approved course to Academy** из исходного репозитория курса; не редактируйте её вручную. Крупные материалы курсов HES размещены в GitHub Releases соответствующего репозитория и требуют подключения к сети. Состав и происхождение каждого выпуска указаны в `release.json` внутри папки курса.

Старые адреса `academy/hes/<курс>/...` перенаправляются на новый сайт основных курсов через страницу 404. История прежних выпусков остаётся доступной в Git, но новые курсы не хранятся в этом репозитории.
