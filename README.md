# Библиотека знаний

Публичная библиотека: https://zhidandbor.github.io/academy/

Этот репозиторий содержит каталог и готовые выпуски курсов. Исходники курсов разрабатываются в их собственных репозиториях.

## Каталог

`docs/index.html` — единственное место редактирования главной страницы библиотеки.
Каждый курс находится в отдельной папке внутри `docs/` и использует собственные ресурсы.

## Выпуск Битрикс24

Папка `docs/bitrix24/` обновляется действием **Publish approved course to Academy** из исходного репозитория курса. Не редактируйте её вручную: изменения должны пройти через исходники и повторный выпуск.

GitHub Pages публикует ветку `main`, папку `/docs`. HTTPS обязателен.
`release.json` в папке курса содержит SHA исходного выпуска. История Git позволяет восстановить прежнюю публикацию.

## Добавление курса

1. Подготовьте самостоятельный выпуск с `index.html` и локальными ресурсами.
2. Добавьте отдельную папку `docs/<course>/`.
3. Добавьте ссылку в `docs/index.html`.
4. Настройте публикацию только папки этого курса из его исходного репозитория.

Рабочие документы, секреты и исходные архивы в публичный репозиторий не включаются.
